# Koersplein — definitieve masterarchitectuur

Status: VASTGEZET. Deze architectuur is de vaste fundering. Nieuwe bronnen, markten en modellen worden als adapters/configuratie/challengers toegevoegd; de kernroute wordt niet ad-hoc gewijzigd.

## Doel
Schat voor ieder aandeel op 3/6/12/24 maanden de volledige rendements-kansverdeling, onzekerheid en downside op basis van uitsluitend informatie die op voorspeldatum werkelijk beschikbaar was. Ontdekkingen uit de toekomst mogen nooit rechtstreeks teruglekken in historische voorspellingen.

## Kernroute
WERELD -> POINT-IN-TIME KNOWLEDGE STORE -> MACHINE 1 (blind) -> WERKELIJKHEID -> MACHINE 2 (forensisch) -> HYPOTHESE -> MACHINE 3 (onafhankelijke falsificatie) -> MACHINE 4 (modelcompetitie) -> NIEUWE MACHINE 1 -> MACHINE 5 (beslissing/portefeuille) -> permanente audit/leercyclus.

Machine 2 mag Machine 1 nooit rechtstreeks wijzigen.

## 14 bouwblokken
1. Universeel Point-in-Time datamodel.
2. Historisch aandelenuniversum incl. IPO/delisting/faillissement/overname/indexhistorie/corporate actions.
3. Bedrijfsfundamentals.
4. Historische verwachtingen, revisions en surprises.
5. Markt/macro/liquiditeit.
6. Relatieve, sector- en netwerkintelligentie.
7. Events, gedrag, nieuws en alternatieve signalen met bewezen timestamps/rechten.
8. Machine 1 definitieve blinde tijdmachine.
9. Machine 2 forensische onderzoeker.
10. Hypothesefabriek plus permanent kerkhof van mislukte hypotheses.
11. Machine 3 onafhankelijke rechter: purged/embargoed walk-forward, untouched data, bootstrap, multiple testing, stabiliteit en markttransfer.
12. Machine 4 modelcompetitie: champion/challenger, ensembles en regimes; alleen OOS-verbetering promoveert.
13. Machine 5 beslissing/portefeuille: rendementskans, downside, onzekerheid, correlatie en allocatie.
14. Permanente leerfabriek/audit: frozen predictions, model/data lineage, drift, kosten en latere beoordeling.

## Architectuurwetten
- Geen toekomstinformatie in Machine 1.
- Geen ontbrekende waarde als nul.
- Geen latere revisie terugschrijven naar het verleden.
- Geen reporting period verwarren met publicatie/beschikbaarheid.
- Geen survivorship bias als eindtoestand accepteren.
- Iedere voorspelling en modelversie wordt bevroren en reproduceerbaar.
- Iedere datapunt heeft bron, tijdlijn, rechten/kwaliteit en integriteit/hash.
- Future evidence is diagnostisch voor Machine 2 en nooit historische feature voor Machine 1.
- Machine 2 produceert hypotheses; Machine 3 probeert ze te falsificeren.
- Geen hypothese verdwijnt omdat hij faalt; alle tests tellen mee voor multiple testing.
- Eindtest/holdout wordt niet gebruikt voor discovery of tuning.
- Geen modelpromotie zonder aantoonbare out-of-sample verbetering.
- AI ontdekt/structureert ongestructureerde informatie; reproduceerbare code/statistiek beslist over bewijs.
- Nieuwe markt = configuratie/universum, geen nieuwe onderzoeksfabriek.
- Nieuwe bron = adapter naar hetzelfde PIT-contract.

## Eindoutput Machine 1
Per instrument, voorspeldatum en horizon: volledige rendementsverdeling plus o.a. verwacht totaalrendement, mediaan, P(rendement>0), relevante upside/downside-kansen, verwachte volatiliteit, modelonzekerheid, regime, positieve/negatieve bijdragen, datakwaliteit en modelversie.
