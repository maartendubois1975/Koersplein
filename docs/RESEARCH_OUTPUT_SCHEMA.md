# Research output contract

Elke Paris-run bewaart een reproduceerbaar manifest plus `base-rates.json`, `blind-forecasts.json`, `forward-outcomes.json`, `hindsight-diagnostics.json`, `validation.json`, `human-conclusion.json/md` en `site-research-output.json`.

## Menselijke conclusie
Moet scope, base rates, signalen, missers, Machine-1-vs-Machine-2, out-of-sample resultaat, beperkingen en de concrete Nederlandse les bevatten. Geen conclusie = run niet compleet.

## Site gate
`site-research-output.json` krijgt `validation_status`, `promoted`, versies, sample size, base rate, conditional hit rate, onzekerheid en positieve/negatieve evidence. Alleen PASS + promoted mag publiek worden.
