# Machine 2 — runcontract

Machine 2 is de leraar van de bevroren Machine 1 en nooit een herschrijver daarvan.

## Volgorde
1. Lees exact het bevroren Machine 1 artifact.
2. Maak één herbruikbaar dossier per onderneming en historische cutoff.
3. Verzamel evidence via geregistreerde providers met caching en provenance.
4. Scheid informatie die op cutoff kenbaar was van gebeurtenissen erna.
5. Onderzoek goede én foute voorspellingen op 3/6/12/24 maanden en toekomstige paden.
6. Zoek terugkerende patronen over aandelen, perioden, regimes en signaalfamilies.
7. Evidence gate weigert niet-tijdige of onvoldoende herleidbare informatie.
8. Leerlaag maakt uitsluitend kandidaat-hypothesen.
9. Alleen een nieuwe blinde out-of-sample Machine 1 test kan een hypothese promoveren.

## Geen zelfbedrog
Geen look-ahead in kenbaar-op-T signalen; geen invullen van ontbrekende waarden; revisions apart; survivorship/universe bias expliciet rapporteren; overlappende horizons niet als onafhankelijke waarnemingen behandelen; effectgrootte, sample size en robuustheid rapporteren; mislukkingen bewaren; geen optimalisatie op dezelfde observaties waarmee een hypothese ontdekt is.

## Schaal
Caching per provider/entity/cutoff, deduplicatie, checkpoints en foutisolatie. Geen scheduler. Externe providers blijven disabled totdat historische point-in-time toegang aantoonbaar beschikbaar is. Daardoor kan de machine veilig draaien zonder fictieve fundamentals, nieuws of analistenhistorie te produceren.
